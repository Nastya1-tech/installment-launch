# Landing «Запуск рассрочки для банков» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Одностраничный двуязычный (RU/EN) тёмный лендинг консалтинга по запуску рассрочки для банков, один файл `index.html`.

**Architecture:** Статический `index.html` в корне репозитория, стили в `<style>`, небольшой встроенный `<script>` только для переключения языка. Каждый переводимый текст дан парой `<span class="ru">` / `<span class="en">` (или `<p class="ru">` / `<p class="en">` для блоков); CSS скрывает неактивный язык по `html[data-lang]`. Проверки делает `check.sh` (grep-утверждения), каждая задача дописывает свои.

**Tech Stack:** HTML, CSS, vanilla JS, sh. Без библиотек, внешних шрифтов и картинок.

**Spec:** `docs/superpowers/specs/2026-10-22-landing-design.md` (читать целиком; источники фактов: `/Users/anastasiya/work/Persona/profile.md`, `/Users/anastasiya/work/Persona/проекты.md`).

## Global Constraints

- Один файл `index.html` в корне `StartUp/landing`, стили внутри `<style>`.
- Нет внешних библиотек, шрифтов, картинок, никаких `http://` и `https://` в файле. Только системные шрифты (`system-ui`).
- Тёмная, технологичная, сдержанная тема; приглушённые цвета, крупная типографика, достаточный контраст.
- Хорошо выглядит на телефоне: `<meta name="viewport" content="width=device-width, initial-scale=1">`, без горизонтальной прокрутки на 320–390 px, кнопка удобна для пальца (высота не меньше 44 px).
- Два языка: RU (по умолчанию) и EN, переключатель RU/EN вверху, без перезагрузки; факты в обеих версиях одинаковые.
- Тон: деловой, от первого лица, на цифрах. Рассрочка честная, без переплат.
- Блоки по порядку: Оффер → Проблема → Цикл → Опыт → Письмо.
- Единственное действие: кнопка `mailto:hello@example.com`; тема письма RU «Запуск рассрочки: обсудить», EN «Installment launch: let's talk» (URL-кодированная). Других контактов нет.
- Подпись: Анастасия Губаревич / Anastasia Gubarevich.
- Запрещено на странице: финансовые цифры (оборот, выручка, рост), модель кросс-продаж (рассрочка как продукт-крючок для кредитов), внутренние данные работодателей, выдуманные цифры, логотипы и картинки брендов.
- Название вкладки: RU «Запуск рассрочки для банков», EN «Installment launch for banks». `meta description` переключается вместе с языком.
- Названия, которые можно использовать (только текстом): MTBank, «Халва» / Halva, «Халва Плюс» / Halva Plus, Umico / Bir, Pasha Bank Georgia, MAIB (Молдова), Coca-Cola, Procter & Gamble, Nestlé, Huggies.
- Факты о цифрах брать только из спеки: 1 500+ партнёров («Халва Плюс»), 2 000+ партнёров (Umico), около 80% покрытия ритейла на каждом рынке (результат, не условие, не в блоке «Проблема»), миллионные клиентские базы, «Халва» — №1 среди карт рассрочки в Беларуси, с 2011, 5+ лет в Umico.

## Review Focus

1. Английский текст длиннее русского не ломает вёрстку на 320 px (нет горизонтальной прокрутки). Проверка в задаче 5.
2. Без JS (или до его запуска) страница показывает русский и рабочую ссылку `mailto:`. Проверка в задаче 1 и 4.
3. После переключения на EN заголовок вкладки, `meta description` и тема письма в `href` тоже английские. Проверка в задаче 1 и 4.
4. На странице нет запрещённых слов («кросс», «NDA», «выручк», «оборот», «cross-sell», «revenue») и нет `http`. Проверка в задачах 1 и 5.
5. В блоке «Проблема» нет «80%». Проверка в задаче 3.

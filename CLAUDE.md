# Карта проекта

## Что это
Лендинг консалтинговой услуги «Запуск рассрочки для банков»: автор (Настя) помогает банку запустить карту рассрочки и выстроить вокруг неё партнёрскую сеть магазинов. У банка есть деньги, клиенты и лицензии, но нет опыта работы с ритейлом. Читатель — представитель банка, единственное целевое действие — написать Насте письмо. Проект учебный.

Идея MVP: прямо на странице блок «Попробуйте сами» (переключатель «Рассрочка / Акция» и плитки магазинов). Это крючок: банкир видит нюансы, о которых не думал, понимает, что это лишь пример, и пишет Насте.

## Что где лежит
- `index.html` — весь сайт в одном файле (стили и скрипт внутри, RU/EN).
- `check.sh` — статические проверки для `index.html` (`sh check.sh`, ждём успех).
- `docs/superpowers/specs/` — дизайн-документы: лендинг и MVP «Рассрочка и акция».
- `docs/superpowers/plans/` — планы реализации.
- `docs/agents/` — настройки для скиллов: где задачи, какие метки, как читать доки.
- `.superpowers/` — служебные файлы процесса.

## Как публикуется сайт
GitHub Pages. После `git push` в `main` сайт обновляется сам: https://nastya1-tech.github.io/installment-launch/

## Как мы работаем
Одна задача на GitHub (Issues этого репозитория) = одна новая сессия Claude. Взяли задачу, сделали, закоммитили, запушили, закрыли задачу, начали следующую в чистой сессии.
